# Обзор безопасности — усиление V3

1. **AutoLiquidity**: резерв, взятый для LP, но не использованный роутером, возвращается в `stockLeft` (раньше он перепродавался как урожай).
2. **CommunityLots**: `MAX_LOT_TOKENS` снижен с 10 млн до 1 млн BILL (100 USDC по цене запуска).
3. **CommunityLots**: `MIN_TWAP_WINDOW` увеличен с 1 ч до 24 ч.
4. **CouncilRegistry**: подписанты выборов не могут быть членами совета.
5. **SolidarityWallet**: получатель не может одобрять собственную заявку.
6. **SolidarityWallet**: лимит на платёж перепроверяется при исполнении.
7. **DeployV3**: деплоер берётся из `vm.readCallers()` при broadcast, чтобы предсказанные адреса CREATE совпадали.

Тесты: 56 проходят. Подробности (FR): `docs/SECURITY.md`.
