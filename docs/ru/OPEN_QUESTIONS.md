# Открытые вопросы

## Утверждённые решения (2026-11-09)
- Основатель сам финансирует 50 USDC начальной ликвидности (вместе с 500 000 BILL).
- Его вознаграждение поступает из 2 % вклада «управление и маркетинг» (`operationsWallet`), без привилегий в токене; его 20 % остаются под вестингом и лимитами продажи.
- Бесплатные лоты содержат такое же количество BILL, как 90 платных лотов серии (рыночная стоимость 100 USDC по курсу TWAP).

- Порог запуска серий: x10 от стартовой цены (0,001 USDC/BILL), утверждён 2026-11-09.
- Анти-sybil: ограничение 1 покупка на кошелёк обходится несколькими кошельками (см. issue #4).
- Программа V4: распределение бесплатных лотов (кампания, 3 администратора по жребию).
- Проверить официальные адреса Uniswap V2 в сети Base (роутер, пара) перед развёртыванием.
- Оракул TWAP поддаётся манипуляциям при высокой, но ненулевой стоимости; минимальное окно 1 ч.
- Тесты в Base Sepolia, анализ Slither, внешний аудит и юридическая проверка перед mainnet.
